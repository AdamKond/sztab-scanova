# DM-y outbound — kampania sushi-lubelskie (sierpień 2026)

Teksty gotowe do wklejenia w Instagram DM. Te same treści siedzą w notatce
każdego leada w SZTAB-ie (import: `npx tsx scripts/import-leady-outbound.ts --wykonaj`).

Zasady wysyłki:
- Wysyłaj 1:1, nie masowo. Możesz podmienić podpis Adam → Oliwier.
- Najpierw priorytet A, potem B. C dopiero gdy A/B odmówią.
- SMS-y dopiero PO uzyskaniu zgody w rozmowie (prawo komunikacji elektronicznej).
- Follow-up bez odpowiedzi: po 3 dniach jedno krótkie przypomnienie, potem wizyta w lokalu.
