# Zrzuty z systemu do tablicy filmiku

Tablica (`docs/tablica-scanovy.html`) sama podmienia odręczne rysunki na
prawdziwe ekrany, gdy w tym katalogu pojawią się pliki PNG o poniższych
nazwach. Brak pliku = zostaje rysunek, nic się nie psuje.

| Plik | Co uchwycić | Jak |
|---|---|---|
| `karta-wallet.png` | Karta Scanovy otwarta w Apple Wallet / Google Wallet (z pieczątkami) | zrzut z telefonu, pion; najlepiej karta MusiSushi/Kago za zgodą albo demo |
| `opinia.png` | Ekran z prośbą o opinię po pieczątce („Podobało się? Zostaw opinię”) | zrzut z telefonu, pion |
| `push.png` | Powiadomienie od lokalu na ZABLOKOWANYM ekranie telefonu | zrzut z telefonu, pion — widać godzinę i banner |
| `panel.png` | Panel właściciela: lista stałych gości / liczby wizyt i opinii | zrzut z przeglądarki, poziom; przytnij do samej treści |

Wskazówki:
- Zrzuty z telefonu rób na pełnej jasności, bez trybu ciemnego (tablica jest jasna).
- Zamaż/wytnij prawdziwe nazwiska klientów, jeśli widać pełne dane.
- Po wrzuceniu plików odśwież tablicę — podpis pod obrazkiem zmieni się na
  „prawdziwy ekran z systemu”.
